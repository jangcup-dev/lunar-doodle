# 음력낙서 (웹)

음력 생신·제사·명절이 해마다 양력으로 며칠인지 계산해 알려 주는 손그림 스타일 기념일 알리미입니다.

- 음력은 천문 계산(태양 황경·삭, 서울 기준 중기 규칙)으로 구하며, 1901–2099년 양↔음 왕복과 2000–2030년 설날·추석 공식 날짜로 검증했습니다.
- 음력 30일이 없는 해는 그믐(29일)로, 윤달생은 평달(선택 시 윤달)로, 제사는 기일 당일 또는 전날 밤으로 챙깁니다.
- 기념일을 휴대폰 캘린더 파일(.ics)로 내보내 알림을 받을 수 있고, 링크로 가족에게 보낼 수 있습니다(정보는 링크 안에만 담기며 서버에 저장되지 않음).
- 계산은 모두 기기 안에서 하고, 기념일은 그 기기의 브라우저에만 저장됩니다. 휴대폰에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있고 오프라인에서도 열립니다.
